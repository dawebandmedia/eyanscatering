# Eyans Catering Services — Bring your people.

## Preview

Extract the ZIP, then open **OPEN-WEBSITE.html** in a modern browser. This file embeds all images, styles, scripts and fonts. It requires no installation or local server. Internet is needed only to open Facebook, email or other external links.

## Editable source

- `index.html`: content, page structure, sections, links and form.
- `styles.css`: visual design, responsive layouts and reduced-motion rules.
- `app.js`: occasion switcher, gallery filters, photo viewer, saved inspiration and three-step planner.
- `assets`: selected original event and food photographs, local fonts and icon.
- `asset-sources.json`: original Facebook photo references.
- `RESEARCH.md`: research findings, excluded expired prices and launch checks.
- `licenses`: bundled open font licence.

After editing the source, run `python build-preview.py` to update OPEN-WEBSITE.html. The normal `index.html` version works with the accompanying assets and can be hosted as a static website. No public deployment was made.

## Planner and contacts

The form creates a message on the visitor's device for review, copying or sending through their own Facebook/email session. It does not automatically send personal data, reserve a date, process a payment or confirm availability. Browser storage keeps only saved inspiration IDs when available. Visitors can remove them from the ticket summary.

Phone and email were verified on the public business page. Commercial terms, current pricing, menus, service arrangements, contact details, branding and photograph permissions need the owner's approval before launch. No expired promotional prices are presented as current.
